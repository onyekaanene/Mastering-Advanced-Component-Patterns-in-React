# Mastering Advanced Component Patterns in React

Move beyond basic components. This tutorial covers four expert-level React patterns that senior developers use to write reusable, scalable, and maintainable UI code.

## What It Covers

- **Compound Components** — building modular, context-aware UI families (Tabs example)
- **Render Props** — injecting flexible rendering logic via function props (Mouse Tracker example)
- **Higher-Order Components (HOCs)** — wrapping components with reusable behaviour (Auth guard example)
- **Controlled vs. Uncontrolled Components** — knowing when React should own the state and when the DOM should

## Why It Matters

Any developer can build a component. Fewer can explain *why* they structured it the way they did. These patterns are the vocabulary of senior React engineers — they show up in technical interviews, code reviews, and production codebases everywhere. Knowing them means writing less duplicated logic, cleaner APIs, and components that other developers actually enjoy using.

## Patterns at a Glance

| Pattern | Core Idea | Real-World Use Case |
|---|---|---|
| Compound Components | Parent + children share context | Tabs, Accordions, Dropdowns |
| Render Props | Pass rendering logic as a function | Mouse tracking, Data fetchers |
| HOCs | Wrap a component to extend it | Auth guards, Logging, Theming |
| Controlled | React state owns the value | Form validation, Live search |
| Uncontrolled | DOM owns the value via `ref` | File inputs, Legacy integrations |

## Tech Stack

- React (hooks-based: `useState`, `useContext`, `useRef`, `createContext`)
- No external libraries — pure React patterns
